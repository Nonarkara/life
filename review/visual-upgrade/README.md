25 October 2026. Source baseline: 0bbc473. Current candidate build: 2215d5022868.

## What was exercised

The lead used the actual browser controls to create a random life, watch the
womb/countdown and annual childhood, reach the first review at 10, choose shared
study at 15, date at 20, commit college at 20–25, and commit an apprenticeship at
25–30. The CV records those completed periods. The flood encounter was resolved
once. Life course switches to the retained Canvas overview and back to 3D.
Money, CV and History remain accessible. Settings changed Thai/English and extra
large/standard type; closing Settings now leaves Resume visible. Daily captions
and moving figures were observed across morning, commute, college, trade, return
and evening. These observations are not a continuous recorded animation review.

The source suite passes 77 tests. The new occlusion guard recreates an off-centre
child under an orthographic camera: the former perspective ray misses the actual
obstruction; the corrected projected-anchor ray finds it. Other guards cover
same-clock pose stability, distance-based gait, supported child seating, pathway
selection and complete-day route clearance. They do not certify artistic quality.

## Reading hierarchy and space

The world and amber protagonist lead; one selected task occupies a content-height
320–360px desktop dock; resource values sit together beneath that task. Phone
recomposes to a closer world above one scrollable task, with persistent navigation.
No new charts were added or stretched. Existing charts retain their actual units
and elapsed-life domains. Controls remain attached to their values. The camera
reserves the dock width, and foreground structures become cutaways only when they
obstruct the actual rig. Place labels moved toward building corners after review
found the school label obscuring some task detail.

## Remaining limits

This is stylized browser 3D, not photorealism or a measured tenfold quality gain.
The independent reviewer inspected source and stills, not uninterrupted live
motion. WebGL-failure recovery and actual OS sleep/background delivery have source
protection but were not fault-injected in the browser. Native editorial review,
full task-contact/actor-avoidance work, recurring human playtests and the broader
handoff simulation backlog remain outstanding. Original-game research is useful
but not exhaustive. No new economic, medical or personality calibration is claimed.

## Public cache defect caught by smoke test
The first upload2215d5022868 passed server byte probes, but an existing public
browser rendered its cached old2D world. DOM showed a new boot URL; the boot
file still imported unversioned game.bundle.js. The asset-reference pattern had
excluded multi-dot filenames. Fixed with a regression for that exact import, and
build identity now includes generated output and the transformation scripts.
Two identical builds agree on befd48c0d958.78tests pass. The screenshot
public-desktop.png records the failed first smoke, never a3D release approval.
